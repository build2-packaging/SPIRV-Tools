# libspirv-tools - SPIR-V assembler, disassembler, validator, and optimizer C++ library

This is a `build2` package for the [`SPIRV-Tools`](https://github.com/KhronosGroup/SPIRV-Tools)
C++ library. It provides an API for assembling, disassembling, validating,
optimizing, linking, linting, reducing, and diffing SPIR-V modules. Public
headers are included as `<spirv-tools/...>`, matching upstream's installed
layout.


## Usage

To start using `libspirv-tools` in your project, add the following `depends`
value to your `manifest`, adjusting the version constraint as appropriate:

```
depends: libspirv-tools ^1.4.357
```

Then import the library target(s) you need in your `buildfile`:

```
import libs = libspirv-tools%lib{SPIRV-Tools}
import libs += libspirv-tools%lib{SPIRV-Tools-opt}
```


## Importable targets

This package provides the following importable targets:

```
lib{SPIRV-Tools}
lib{SPIRV-Tools-opt}
lib{SPIRV-Tools-link}
lib{SPIRV-Tools-lint}
lib{SPIRV-Tools-reduce}
lib{SPIRV-Tools-diff}
```

`lib{SPIRV-Tools}` is the core assembler, disassembler, and validator.
`lib{SPIRV-Tools-opt}` is the optimizer and depends on the core library.
The remaining targets are the linker, linter, reducer, and diff libraries.
Each depends on `lib{SPIRV-Tools-opt}`. Target names match upstream's CMake
libraries.

Typical includes:

```
#include <spirv-tools/libspirv.h>
#include <spirv-tools/libspirv.hpp>
#include <spirv-tools/optimizer.hpp>
#include <spirv-tools/linker.hpp>
#include <spirv-tools/linter.hpp>
```

The `spirv-fuzz` library is not built. It needs protobuf and is optional
upstream.


## Configuration variables

This package has no configuration variables.

The libraries are compiled with exceptions and RTTI disabled, matching
upstream. Grammar tables and debug-info language headers are generated by
the packager from `libspirv-headers` (no Python at consumer build time).
The package version follows the Vulkan SDK tag (`1.4.357` for
`vulkan-sdk-1.4.357.0`).
